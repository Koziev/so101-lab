# Mechanical assembly

Use this page as a build log for the physical arm.

## Suggested sequence

1. Verify all printed parts and purchased components against the selected assembly revision.
2. Check servo labels, shaft interfaces, horns, and fasteners before mounting.
3. Assemble one joint at a time, checking alignment and cable routing.
4. Move each joint gently through its intended range before powering the complete arm.
5. Photograph each stage and record any deviations from the reference assembly.

## Build notes

Add dated subsections as the assembly progresses. Include close-up photographs of non-obvious orientations, fastener lengths, and cable routing.
