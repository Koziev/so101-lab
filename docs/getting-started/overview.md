# Project overview

## Scope

SO-101 Lab documents the construction and experimental use of a low-cost robotic manipulator. It is intended to serve both as a chronological lab notebook and as a structured technical reference.

The project currently covers:

1. Printing and assembling the SO-101 follower.
2. Configuring serial bus servos and the motor controller.
3. Calibrating joints and developing safe teleoperation utilities.
4. Connecting the robot to LeRobot.
5. Building simulation models and testing control ideas.
6. Exploring visual and language-conditioned manipulation.

## How to use this documentation

The **Assembly** section records physical construction and setup procedures. **Experiments** contains focused notes about software and control experiments. The **Blog** is chronological and captures the context behind changes and discoveries.

Treat a page as a reproducible procedure only when its prerequisites, settings, and verification steps are explicitly documented.
